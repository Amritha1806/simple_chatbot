# Simple Python Chatbot

## About
This is a beginner-friendly chatbot developed using Python. It responds to simple user messages using predefined conditions.

## Features
- Responds to greetings such as hello and hi.
- Answers simple questions.
- Responds to thank-you messages.
- Ends the conversation when the user types `bye`.

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

## Purpose
This project was created to learn Python programming, conditional statements, loops, and basic chatbot logic.
